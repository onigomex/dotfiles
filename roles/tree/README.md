# roles/tree
ディレクトリ構成を木で表示する



## Dependencies
- homebrew



## Usage
```
tree -L 2             # 深さ 2 まで（既定は無制限で長くなりがち）
tree -a               # 隠しファイルも
tree -d               # ディレクトリだけ
tree -I node_modules  # 除外
```
