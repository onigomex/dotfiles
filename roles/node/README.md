# roles/node
Node.js: JavaScript runtime (npm / npx bundled)



## Dependencies
- homebrew



## Notes
- Homebrew の素の node を入れる（npm・npx が同梱される）。`npx <pkg>` で npm 製 CLI をアドホックに実行できる。
- プロジェクトごとに node バージョンを固定したくなったら、mise / fnm などのバージョン管理へ移行する（その場合はこの role を差し替える）。
