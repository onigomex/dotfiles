# roles/csview
CSV を罫線付きの表で読む。日本語も絵文字も崩れない



## Dependencies
- homebrew



## Usage
```
csview <file.csv>     # 罫線付きの表で表示
csview -s ';'         # 区切り文字を指定
cat foo.csv | csview  # パイプでも受けられる
```
